# 明日方舟 24×24 像素画自动填色

一个面向 Windows 的明日方舟 PC 客户端辅助工具，可将用户选择的图片转换为游戏40色调色板下的 `24×24` 像素画，并在用户确认后自动填入游戏编辑画布。

## 界面预览

![明日方舟24×24像素画自动填色工具界面](docs/images/ui-overview.png)

> 截图展示 v1.2.0 的真实界面：三栏同步紧凑布局、算法选择、画板行列坐标，以及画板与调色板的色号对照功能。

## v1.2.0 本次更新

- 修复窗口缩小时只有中央画板缩放、左侧图片处理栏不跟随的问题；紧凑模式会同步调整字体、控件间距、顶部主题区和底栏，不再显示常驻滚动条。
- 新增 GitHub Release 自动检查：程序启动后在后台检查最新版，不阻塞本地功能；发现新版本时会在右下角显示更新按钮，由用户确认后打开浏览器下载。
- 新增 **显示色号** 开关：开启后，中央24×24画板与右侧40色调色板会同步显示 `1–40` 色号；画板顶部和左侧同时显示 `1–24` 列号、行号，并将第12格分界线与外框加粗，方便定位四个12×12区域。
- 新增启动前管理员权限检查：权限不足时显示提示，确认后立即退出，不加载主界面或后台线程。
- 新增4种缩放取样算法与2种颜色匹配算法，可根据素材自由组合并实时比较预览。
- 新增“减少过渡色（最多16色）”开关；开启时自动关闭抖动，使色块更清晰。
- **跳过白色格** 现在默认开启，适用于游戏画布初始状态为纯白底色的情况。
- 窗口最小尺寸从1180×760降低至约920×660，预览画布可缩小到240×240并保持24等分。

## 主要功能

- 将本地图片缩放和量化为 `24×24` 像素画。
- 支持直接导入别人已经制作好的 `24×24 PNG` 位图，跳过裁切、拉伸和尺寸重采样，逐像素覆盖预览画布。
- 上传图片后可通过独立裁切窗口移动、缩放并1:1裁切需要的区域。
- 映射到游戏内40种可用颜色。
- 缩放取样算法可选择 **Lanczos（原版）**、**BOX（减少混色）**、**Bicubic（柔和）** 或 **Nearest（像素画）**。
- 颜色匹配算法可选择 **经典RGB（原版）** 或 **OKLab（感知）**，方便针对不同素材比较结果。
- 可选 **减少过渡色（最多16色）**，合并低频过渡色，使人物轮廓和色块更清晰。
- 支持 `crop`、`contain` 和 `stretch` 三种图片适配方式。
- 可选 Floyd–Steinberg 抖动。
- 支持在24×24预览区内手动涂色、吸色、撤销和恢复转换结果。
- 支持在中央画板和右侧调色板中同步显示色号，直接按 `1–40` 对照修改；画板行列坐标及12格加粗分界可以辅助快速定位。
- 启动后自动在后台检查 GitHub Release；仅发现更高版本时显示更新入口，下载前仍由用户确认。
- 自动定位明日方舟 Unity 游戏窗口。
- 自动识别24×24网格线，减少不同DPI下的累计坐标偏差。
- 自动切换和滚动右侧调色板。
- 支持不同游戏客户区分辨率，并根据实际客户区和识别到的网格动态换算坐标。
- 支持1080p、2K、4K等不同屏幕分辨率、多显示器布局及不同Windows缩放倍率。
- 支持 `F8` 紧急停止。
- 工具窗口会按当前屏幕工作区、分辨率和DPI确定初始尺寸，并常驻Windows任务栏。
- 支持整体拖动、边缘缩放、最大化及响应式布局；预览画布和调色板会随可用空间调整。

## 缩放与颜色算法对比

![Lanczos、BOX、Bicubic、Nearest与经典RGB、OKLab对比](docs/images/algorithm-comparison.png)

- 横向依次为 `Lanczos`、`BOX`、`Bicubic`、`Nearest`。
- 上排使用经典RGB匹配，下排使用OKLab感知匹配。
- 普通插画建议先使用默认的 `Lanczos + 经典RGB`；希望减少混色时可尝试 `BOX`；已有像素素材可尝试 `Nearest`。
- OKLab不是对所有素材都一定更好，请以软件实时预览为准。

## 使用前必读

> [!IMPORTANT]
> 正式支持明日方舟 **PC客户端官服与B服**。模拟器原理上可以使用，评论区已有成功反馈，但需要用户自行调整模拟器内部的分辨率、缩放倍率和窗口标题关键字；手机端、云游戏和远程桌面不在兼容保证范围内。

工具已经适配不同游戏客户区分辨率、屏幕分辨率和Windows显示缩放倍率。自动填色时会读取游戏实际客户区位置，并优先识别24×24网格进行坐标校准；工具界面也会根据当前工作区和DPI自适应。

不同游戏版本、显卡缩放方式及系统DPI组合仍可能影响图像识别。为获得最稳定的坐标和调色板操作，建议优先使用以下设置：

| 项目 | 建议设置 |
| --- | --- |
| 游戏客户端 | **PC官服、PC B服正式支持**；模拟器需自行适配 |
| Windows 显示缩放 | 支持不同倍率，**100% 最稳定** |
| 游戏 UI 缩放 | 支持校准适配，**100% 强烈推荐** |
| 游戏客户区分辨率 | 支持多种分辨率，**1280×720 强烈推荐** |
| 窗口模式 | 窗口化或无边框窗口，不要跨两块屏幕 |
| 界面状态 | 24×24编辑画布和右侧调色板完整可见 |

换言之，多分辨率与多缩放倍率属于已支持场景，而不是必须固定为1280×720才能运行；但 `游戏客户区 1280×720 + 游戏 UI 100%` 是测试最充分、成功率最高的推荐组合。Windows显示缩放也建议优先使用100%。

## 客户端兼容性

### PC客户端

- 正式支持明日方舟PC客户端的 **官服** 与 **B服**。
- 默认窗口标题关键字使用 `明日方舟`，通常无需修改。
- 支持不同客户区分辨率、屏幕分辨率和常见Windows缩放倍率。

### 安卓模拟器

- 原理上支持模拟器，评论区已有用户反馈可以正常使用，但不同模拟器的渲染窗口、内部DPI和缩放方式差异较大，因此不作为开箱即用的保证场景。
- 需要在模拟器内部调整游戏分辨率和缩放倍率，使24×24画布与右侧调色板完整可见；建议先尝试 `1280×720 + 游戏UI 100%`。
- 在工具的 **游戏窗口标题关键字** 中，将默认的 `明日方舟` 改为对应模拟器窗口的实际名称，例如模拟器标题栏中显示的名称。
- 游戏必须完整位于同一块显示器内，开始填色后不要移动、缩放或切换模拟器窗口。
- 如果出现选色偏移、调色板无法下拉或整行整列空白，请优先调整模拟器内部的分辨率与缩放，而不仅是Windows显示缩放。

## Windows 显示缩放设置

1. 打开 Windows **设置**。
2. 进入 **系统 → 屏幕**。
3. 找到 **缩放** 或 **缩放与布局**。
4. 工具支持100%、125%、150%、200%等常见缩放倍率；如出现定位偏差，优先将运行游戏的显示器调整为 **100%**。
5. 使用双屏时允许显示器采用不同分辨率和缩放倍率，但游戏窗口必须完整位于同一块显示器内，不要跨屏。
6. 修改缩放倍率后，建议重新启动游戏和本工具，让双方重新读取DPI状态。

## 使用方法

### 正常启动方式

1. 推荐右键 `明日方舟像素画自动填色.exe`，选择 **以管理员身份运行**。
2. 如果希望以后直接双击启动，可右键EXE进入 **属性 → 兼容性**，勾选 **以管理员身份运行此程序**，应用后再双击启动。
3. Windows显示用户账户控制提示时选择 **是**，随后进入主界面。
4. 直接双击但未取得管理员权限时，程序只会提示“需要管理员权限”，点击确定后自动退出，这是预期行为。

### 1. 准备游戏

1. 启动明日方舟PC官服、B服客户端，或已经完成分辨率和缩放设置的模拟器。
2. 工具支持不同游戏UI缩放状态，但建议将游戏 UI 缩放调整为 **100%**。
3. 进入24×24像素画编辑页。
4. 确保画布和右侧调色板没有被聊天窗口、浏览器或其他程序遮挡。
5. 如果使用模拟器，将工具中的 **游戏窗口标题关键字** 修改为对应模拟器窗口的实际名称。

### 2. 导入和调整图片

1. 右键本工具并选择 **以管理员身份运行**。程序启动前会检查权限；非管理员启动只显示提示，确认后立即退出。
2. 普通图片点击 **选择图片**，选择后会自动打开裁切窗口。
3. 在裁切窗口中：
   - 拖动裁切框内部：移动裁切区域。
   - 拖动四个角：改变裁切区域大小。
   - 鼠标滚轮：以中心为基准缩放裁切框。
   - **重置裁切**：恢复默认的1:1裁切区。
   - **应用裁切**：将选中区域用于后续24×24转换。
4. 如需再次调整，点击主界面的 **裁切** 按钮。
5. 根据需要选择缩放方式：
   - `crop`：居中裁剪为正方形，画面会铺满24×24网格。
   - `contain`：保留完整画面，空白部分用白色填充。
   - `stretch`：不保持原始比例，直接拉伸到24×24。
6. 在 **缩放取样算法** 中选择需要的方案：
   - `Lanczos（原版）`：默认设置，细节较丰富，兼容旧版结果。
   - `BOX（减少混色）`：色块更稳定，适合人物立绘和图标。
   - `Bicubic（柔和）`：过渡较平滑，适合照片。
   - `Nearest（像素画）`：不进行平滑插值，适合已有像素风格的素材。
7. 在 **颜色匹配算法** 中选择 `经典RGB（原版）` 或 `OKLab（感知）`。默认使用经典RGB，部分肤色、紫色和深蓝素材可以尝试OKLab并比较预览。
8. 如果图片出现过多过渡色、整体显得模糊，可开启 **减少过渡色（最多16色）**。该模式会自动关闭抖动，并可能减少渐变和少量装饰色。
9. 照片或渐变素材可根据需要开启 **Floyd–Steinberg抖动**；人物立绘和图标通常建议关闭。
10. 在中央预览区检查转换结果，并使用右侧调色板进行手动修整。

如果图片本身已经是别人制作好的24×24像素画，可以改用 **导入24×24 PNG位图**：

- 文件必须是PNG格式，且尺寸必须恰好为 `24×24` 像素。
- 导入过程不会调用Lanczos或其他尺寸重采样，也不会裁切、填边或拉伸图片。
- 每个像素会直接对应预览画布中的一个格子；已经属于游戏40色的像素会原样保留。
- 不属于游戏40色的像素仍会映射到最接近的游戏颜色，透明像素按白色处理。
- 位图直导后仍可在预览区手动涂色、吸色、撤销、恢复，并正常执行自动填充。

### 3. 手动修改像素画

- 勾选中央预览标题旁的 **显示色号**，画板每个像素和右侧调色板会显示相同的 `1–40` 编号。
- 开启色号后，画板顶部显示列号、左侧显示行号，范围均为 `1–24`；第12行、第12列的分界线和画板外框会加粗，橙色的 `12`、`24` 标签可用于快速辨认区域。
- 再次取消勾选即可隐藏色号与行列坐标，恢复纯色预览。
- 在右侧调色板中点击需要的颜色。
- 预览区左键点击或拖动：涂色。
- 预览区右键：吸取当前格子颜色。
- **撤销**：撤销上一次手动笔画。
- **恢复转换结果**：放弃手动修改，恢复到当前图片的转换结果。

### 4. 调整工具窗口

- 按住顶部自定义标题栏拖动，可以移动整个工具窗口。
- 拖动窗口四边或四角，可以放大或缩小窗口；新版允许缩小到约920×660，具体像素会根据当前DPI比例换算。
- 窗口高度较小时会自动切换三栏同步紧凑布局，左侧图片处理控件、中央预览、顶部主题区和底栏会一起收紧，不再常驻显示左侧滚动条。
- 点击标题栏右上角的最大化按钮，或双击标题栏，可以最大化/还原窗口。
- 中央24×24预览会随窗口缩放，并始终保持24的整数倍尺寸，避免手动涂色坐标错位。
- 右侧调色板会根据可用区域重新计算色块大小，颜色选择位置会同步更新。
- 窗口可从Windows任务栏最小化和恢复；如果任务栏仍显示旧行为，请完全退出旧版本后再启动新版程序。

### 5. 开始自动填色

1. 确认 **游戏窗口标题关键字**：PC官服/B服填写 `明日方舟`，模拟器填写对应模拟器窗口的实际名称。
2. 建议保持默认每格点击间隔 `0.060 s`。
3. **跳过白色格默认开启**，仅适用于游戏画布已经是纯白底色的情况；如果需要主动重新填充白色像素，请关闭该选项。
4. 点击 **开始自动填充**。
5. 确认提示后，工具会切换到游戏窗口，截取当前客户区并尝试识别实际网格。
6. 自动填色过程中不要移动鼠标、切换窗口、改变游戏分辨率或拖动游戏窗口。
7. 如需紧急停止，按 `F8`。

## 自动校准状态

填色完成后，工具底部会显示定位状态：

- `定位：自动校准 xxx×xxx px`：成功识别游戏当前24×24网格。
- `定位：比例坐标`：自动识别未通过，工具已回退到固定比例坐标。此时请重点检查UI缩放、分辨率和画面遮挡。

## 常见问题

### 找不到游戏窗口

- PC官服/B服请确认窗口标题关键字为 `明日方舟`。
- 模拟器请将窗口标题关键字改为模拟器窗口标题栏中显示的实际名称。
- 确认游戏已经启动，且窗口没有完全最小化。

### 鼠标在游戏内不移动

- 新版本必须以管理员身份运行；如果权限不足，程序会在主界面出现前提示并退出。
- 右键EXE选择 **以管理员身份运行**，通过Windows权限确认后再进行自动填充。

### 出现整行或整列空白

- 多分辨率和缩放倍率虽已支持，但排查问题时请先恢复为游戏客户区1280×720、游戏UI缩放100%。
- 如果仍有偏差，再将运行游戏的显示器缩放调整为100%，并重新启动游戏和工具。
- 确认画布没有被其他窗口遮挡。
- 检查完成状态是否显示“自动校准”。

### 调色板颜色选偏或无法下拉

- 将游戏UI缩放恢复为100%。
- 使用1280×720窗口，并保证右侧调色板完整可见。
- 在开始填色前不要将其他窗口覆盖在调色板上。
- 尝试将每格点击间隔调整为 `0.080 s` 或更高。

### 双屏环境错位

- 确认 Windows 使用“扩展这些显示器”，而不是复制模式。
- 支持显示器使用不同分辨率和缩放倍率；发生错位时，可暂时将运行游戏的显示器改为100%缩放进行排查。
- 将游戏窗口完整放在某一块显示器内，不要跨屏。

### 工具窗口无法拉大或拖动时内容没有跟随

- 请确认运行的是最新生成的 `明日方舟像素画自动填色.exe`，而不是旧版或带其他后缀的测试版本。
- 完全退出任务管理器中的旧版程序后再启动新版。
- 可拖动窗口边缘或四角调整大小，也可双击顶部标题栏最大化。

### 没有出现版本更新提示

- 更新检测在程序启动后后台执行，网络不可用时不会弹出错误，也不会影响图片转换和自动填色。
- 只有 GitHub Release 的版本号高于当前程序版本时，右下角才会显示更新按钮。
- 如果所在网络无法访问 GitHub，可继续通过B站评论区或置顶评论中的夸克网盘链接手动检查和下载。

## 运行源码

需要 Windows、Python 3.10 或更高版本，并在管理员权限的PowerShell中运行。

```powershell
git clone https://github.com/JayJokerr/arknights-pixel-autofill.git
cd arknights-pixel-autofill
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python arknights_pixel_autofill.py
```

## 打包 EXE

```powershell
pip install -r requirements-dev.txt
pyinstaller --noconfirm --clean arknights_pixel_autofill.spec
```

打包结果位于 `dist/`。本地 `assets/` 为可选界面素材且不纳入Git；缺少时仍可运行和打包，但界面不会显示这些装饰图片。

## 项目结构

- `arknights_pixel_autofill.py`：主程序。
- `arknights_pixel_autofill.spec`：PyInstaller打包配置。
- `requirements.txt`：运行依赖。
- `requirements-dev.txt`：打包和开发依赖。
- `assets/`：本地可选界面素材，不纳入Git。
